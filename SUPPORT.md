# SESAME Support

SESAME is currently an unsupported developer scaffold. It is not ready for
production identity data or authentication traffic.

Use:

- GitHub issues for reproducible bugs and scoped feature proposals;
- GitHub discussions, when enabled, for design and deployment questions;
- private vulnerability reporting for security issues.

Before filing a bug, include the SESAME version output, operating system and
architecture, reproduction steps, expected behavior, actual behavior, and
sanitized logs. Never post credentials, tokens, personal data, or private keys.

Platform and protocol support exists only when the evidence described in
`docs/RELEASE_ENGINEERING.md` and `docs/PROJECT_PLAN.md` is published.
